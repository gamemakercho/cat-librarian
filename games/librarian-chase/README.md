# 사서를 잡아라!

기존 방탈출의 마지막 추격 게임. `ending-rescue`의 시작 버튼에서 이 폴더를 iframe으로 엽니다.

- 30초 달리기, 체력 3, 2단 점프, 실패 재도전
- 성공 후 원본 1536×1024 엔딩 이미지 5장
- 만화 끝에서 검증된 ending-contact 메시지로 본편 엽서 문제에 복귀
- 정답/성공 팝업 뒤 기존 restore와 최종 완료로 연결

직접 이 폴더의 index.html을 열어 HTTP로 플레이하면 엽서 입력과 독립 완료까지 체험할 수 있습니다. 본편 iframe에서는 자체 완료 기록을 읽거나 쓰지 않습니다.

설정은 config.js에 모았습니다. 상대 경로이므로 GitHub Pages의 /cat-librarian/ 하위 경로에서도 동작합니다. 제공된 스프라이트·만화는 SOURCE.json에 기록한 원본 해시를 유지합니다. 개발 참고 시안과 실제 엽서 원본은 배포하지 않습니다.

루트에서 `npm test`, `npm run check`로 추격 규칙·화면 상태·iframe 계약·기존 방탈출 회귀·자산을 함께 검사합니다. 브라우저 검증 제한은 루트 docs의 검증 보고서를 참고하세요.
