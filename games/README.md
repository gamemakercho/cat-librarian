# 본편용 기존 게임 사본

기존 `library-game1`과 `bookband`의 완전한 실행 코드·WebP·스프라이트 JSON을 이 폴더로 가져왔다. 원본 출처는 `origins.json`에 기록했다. 코드 스냅샷만으로 게임을 재작성하지 않았다. 외부 원본 저장소는 이번 작업에서 수정하지 않았다.

## 보존한 동작

- book-catch: 30초,20권 목표,카트5권,1~4열 이동과 책 꽂기,기존 결과/그림/PERFECT 연출.
- book-order: 000~900 열 권,끌어 꽂기·찬 자리 밀어 넣기·탭/접근성 조작,시간 제한 없음,원래 저장/복원.
- 모든 실행 WebP/JSON의 해시와 book-catch의 engine.js/config.js,book-order의 state.js/geometry.js 원본 해시는 `origins.json`에 있다. `node scripts/check-assets.mjs`를 저장소 최상위에서 실행하면 검증한다.

## 본편용 수정

`story-adapter.js`/`.css`는 검증된 부모 origin·세션·게임ID가 있는 임베드 모드에서만 활성화된다. 원래 index/style/game/config에 연결해 짧은 시작 안내,성공 결과의 큰 ‘성공! 사서를 따라가자!’,작은 ‘다시하기’,고정 높이와 내부 결과창 스크롤을 제공한다. 책 받기 성공은 원래 finish()의 won 결과,책 꽂기는 원래 state.complete 결과를 사용한다. 실패에는 재도전만 표시한다.

2026-10-15 최신 요청으로 키워드 UI를 제거했다. 완료 이벤트는 본편에 검증된 결과를 저장하며 자동 진행하지 않는다. 성공 결과의 큰 버튼을 눌러야 다음 이야기로 이동한다. 게임 중 상단 복귀와 추가 키워드 칭찬 팝업은 없다. 저장된 성공 뒤 본편을 새로고침하면 본편의 같은 큰 성공 버튼으로 이어간다. 이전 키워드 방식의 ID는 저장 호환용으로만 유지한다.

책 꽂기의 저장 키/게임ID는 본편 runId를 덧붙인다. 같은 플레이는 이어하고,전체 처음부터는 예전 완료를 상속하지 않는다. 임베드 모드의 자동 다음 URL은 비운다. 독립 실행은 기존 도입·설정을 유지한다.

게임은 본편 시작 버튼에서만 로드한다. PNG 원본,미사용 이미지,제작 참고,코드 스냅샷은 복사하지 않았다. 본편의 기존 청소 게임 연결은 별도 외부 저장소를 사용하며 이번에 변경하지 않았다.
